# 大师级电影调色与复古胶片滤镜 (Cinematic & Film FX v1.0.0)

OpenLVET 专属高精度 WebGL 着色器电影滤镜包。

### 包含滤镜：
1. **🎬 好莱坞青橙 (Teal & Orange)**：好莱坞大片冷暖分离色调。
2. **🎞️ 复古胶片颗粒 (Vintage Film Grain)**：柯达 35mm 胶片动态噪点颗粒、暗角与温感。
3. **🌸 日系清透柔光 (Anime Pastel Dream)**：通透日系高光漫反射与柔光粉蓝调。

### 使用方法：
- 在时间线上选中任意视频或图片片段。
- 在左侧资产面板「🎬 电影滤镜」或「✨ 特效」面板中点击即可实时应用。
- 选中的片段可在右侧属性面板实时调节滤镜浓度、颗粒度、暗角与曝光度！
