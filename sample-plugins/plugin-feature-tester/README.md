# 全能插件功能测试套件 (Plugin Feature Tester v1.0.0)

用于全面测试 OpenLVET 插件系统所有扩展点与能力的集成测试插件。

### 已激活的扩展点：
1. **左侧资产面板 Tab**：在左侧注册「🧪 插件测试」面板。
2. **右侧属性面板 Tab**：在右侧属性栏注册「🧪 测试属性」Tab（支持查看与修改选中片段属性）。
3. **时间线工具栏**：在时间线顶部工具栏注册「⚡ 工具栏扩展」按钮。
4. **顶部全局导航栏**：在顶部左侧注册「🧪 插件测试」诊断按钮。
5. **视口 HUD 探针**：在播放视口右上角渲染实时毫秒时间戳浮层。
6. **WebGL 着色器特效**：在原生特效库中注册「🧪 测试扫描反色」动态滤镜。
7. **持久化与响应式配置**：测试插件独立 Storage 读写与动态配置变更。
